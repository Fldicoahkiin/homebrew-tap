# Steam Cloud File Manager Homebrew Tap

This is the official Homebrew tap for [Steam Cloud File Manager](https://github.com/Fldicoahkiin/SteamCloudFileManager).

## Installation

```bash
brew tap Fldicoahkiin/tap
brew install steam-cloud-file-manager
```

## Usage

```bash
# Run from terminal
steam-cloud-file-manager

# Or open the app directly
open "$(brew --prefix)/Cellar/steam-cloud-file-manager/*/Steam Cloud File Manager.app"
```

## Update

```bash
brew update
brew upgrade steam-cloud-file-manager
```

## Uninstall

```bash
brew uninstall steam-cloud-file-manager
brew untap Fldicoahkiin/tap
```
